Sessions manage themselves

A download or build runs 6 minutes? AutoBG moves it to background automatically — you keep typing, the tool keeps running.

AutoBG — the session that moves itself

When a tool (a download, a build, a script) keeps the session blocked for over 1 minute, the plugin runs exactly what Ctrl+B runs — the session moves to background, with a heads-up toast first.

  • Heads-up: one toast at 45s — AutoBG: 15s — "bash" moves to background automatically
  • Nothing dies: backgrounding never kills the tool — the engine's own contract
  • Tools only: a model thinking/writing for 10 minutes is never touched
  • Multi-agent safe: several OpenCode windows at once? an NTFS-atomic lock means exactly one move fires
  • Subagent-safe: child sessions are never detached from their parent

Thresholds are two constants at the top of autobg.ts (THRESHOLD_MS = 60_000, WARN_BEFORE_MS = 15_000). If your build dropped the toast route, the countdown is still logged to debug.log.

  1. 0:00 You start a download inside a session
  2. 0:45 Toast: "AutoBG: 15s left" — you know it's coming
  3. 1:00 Session moves to background (the Ctrl+B operation)
  4. after Tool keeps running · your foreground is free · next long run arms itself again

Where it runs, what it touches

  • Runs inside OpenCode itself — it reads the local event stream on localhost, nothing leaves your machine
  • Zero dependencies, zero child processes, no background services, no telemetry
  • Works on Windows, macOS, Linux
  • Detects old (v1) and new (v2) OpenCode engines automatically
  • Nothing to configure — drop the files, restart, done

Get it in 60 seconds

Hindi: 3 step — files copy karo, OpenCode pura band karke kholo, picker khol ke dekho.

Copy the plugin into OpenCode's plugins folder

Windows (PowerShell) 
git clone https://github.com/engrtarun/opencode-model-badges "$env:USERPROFILE\model-badges"
cd "$env:USERPROFILE\model-badges"
$dst = "$env:USERPROFILE\.config\opencode\plugins\model-badges"
New-Item -ItemType Directory -Force -Path $dst | Out-Null
Copy-Item index.ts, lib.ts, autobg.ts, package.json $dst
macOS / Linux (bash) 
git clone https://github.com/engrtarun/opencode-model-badges ~/src/model-badges
cd ~/src/model-badges
mkdir -p ~/.config/opencode/plugins/model-badges
cp index.ts lib.ts autobg.ts package.json ~/.config/opencode/plugins/model-badges/

No git? Download the 4 files (index.ts, lib.ts, autobg.ts, package.json) from the repository and place them in that same folder yourself.

Restart OpenCode — fully

Close the app and open it again (a fresh tab is not enough — the plugin loads with the server).

Open the model picker

Badges appear on every name. Start any tool that runs over a minute — watch AutoBG move it. That's it, nothing to configure.

Questions people actually ask

Does it send anything to the internet?
No. It reads OpenCode's local event stream on your own machine and updates text in your picker. The only network calls are to your own local OpenCode server.
Will it slow OpenCode down?
It is one file of TypeScript listening to events — no child processes, no dependencies, and per-session state is cleaned up automatically. It costs roughly the RAM of a text file.
I restarted but I don't see any badges / toasts
Check the plugin folder has all 4 files and that OpenCode was fully closed and reopened. Some builds dropped the toast route — AutoBG then logs its countdown to ~/.config/opencode/plugins/model-badges/debug.log and still performs the background move.
Does AutoBG ever kill my running tool?
No. Moving a session to background keeps the tool running — that is OpenCode's own behavior when you press Ctrl+B too. The plugin only presses that same operation for you.
Can I change the 1-minute threshold?
Yes — two constants at the top of autobg.ts: THRESHOLD_MS and WARN_BEFORE_MS. Edit, restart, done.
How do I remove it?
Delete the folder ~/.config/opencode/plugins/model-badges. No config entries, no registry, no cleanup needed.
